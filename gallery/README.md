# Haptic Design Lab Gallery

동운아나텍 햅틱 디자인 랩의 포트폴리오·갤러리 웹페이지. 고객사에 "DWA 햅틱 어플리케이션은 다양하고 드라이버 + 데모 라인업이 충분하다"를 전달하는 용도.

## 현재 상태 (2026-11-09)

- 샘플 완성: 기존 등록된 데모기 22건 + 의뢰 작업 5건 + 랩 도구 4종 + 드라이버 IC 6종
- 사진: 아직 없음 → 전시마다 `PHOTO · 추가` 자리표시가 표시됨
- 로고·슬로건·문의 링크: 임시(플레이스홀더)
- 고객사: 실명 없이 산업·국가로 표기 (공개 범위 미확정)
- 연도·액추에이터 정보: 미확정이라 표시하지 않음

## 폴더 구성

```
gallery/
├─ index.html              # 페이지 (더블클릭으로 열림, 서버 불필요)
├─ data/exhibits.js        # 전시 데이터 단일 출처 — 데모기 추가는 여기만 수정
├─ assets/
│  ├─ css/gallery.css
│  ├─ js/gallery.js
│  └─ photos/
│     ├─ _inbox/           # 사진을 일단 여기에 던져 넣는 곳 (이름 자유)
│     └─ <전시 id>/        # 정리된 사진: 01.jpg, 02.jpg ...
└─ design/                 # 디자인 초안 원본(캔버스 아트보드 3종)
```

## 데모기 추가·수정

1. `data/exhibits.js`의 `EXHIBITS` 배열에 항목 추가 (필수: id, wing, status, title, feel, ic, photos, purpose, specs, highlights, deploy)
2. 새 분류가 필요하면 `WINGS`에 추가
3. 의뢰 작업으로 보여줄 건은 `COMMISSIONS`에 추가

## 사진 추가 방법

| 방법 | 절차 | 비고 |
|---|---|---|
| A. 폴더에 직접 넣기 (권장) | `assets/photos/<전시 id>/`에 `01.jpg`로 저장 → `exhibits.js`의 `photos: ["01.jpg"]` 갱신 | 가장 단순, Git으로 버전 관리 |
| B. `_inbox`에 일괄 투입 | 사진을 `_inbox/`에 넣고 Claude에게 "어느 사진이 어느 전시인지" 알려 주면 이름 정리·배치·데이터 갱신을 대신 수행 | 파일명에 전시 id를 붙이면 더 빠름 (예: `hvac_01.jpg`) |
| C. PPT 전달 | PPT를 `_inbox`에 넣거나 채팅에 첨부 → Claude가 슬라이드별 이미지를 추출해 배치 | 슬라이드 제목에 전시 이름을 적어 두면 자동 매칭 |
| D. 채팅 업로드 | 채팅에 이미지를 올리고 전시 이름을 알려 줌 | 소량일 때 |
| E. Notion 내보내기 |  (Notion 원본 매핑 파일은 내부 정보라 이 저장소에는 올리지 않음)

사진 규격 권장: 가로 1600px 이상, JPG/WebP, 전시당 1~4장, 파일당 500KB 이내.

## 열린 결정

- 로고(SVG 또는 링크)와 슬로건 확정
- 고객사 공개 범위 (실명 / 산업·국가 / 익명)
- 전시실(다크)·랩(라이트) 톤 확정
- 연도, 액추에이터 등 캡션 항목 추가 여부
- KO/EN 전환 (해외 지사 공유 시)
- 호스팅 방식 (사내 공유 폴더 / GitHub Pages 등)

## 데이터 정정 내역 (기존 카탈로그 대비)

- HVAC: 1·2단계(DW7917 LRA, DW3M120 Piezo) 모두 제작 완료로 정정
- NHK 항목: 방송 인터랙션 데모가 아니라 ADAS Haptic PAD (8CH, 좌·우 경고 진동, 일본 자동차 부품 제조사向)로 정정, 분류를 자동차로 이동
- 고객사 실명(미쓰비시, 현대차 등)은 산업·국가 표기로 대체
