# Haptic Design Lab — 웹 미리보기

동운아나텍 Haptic Design Lab 브랜딩 프로젝트의 웹 소개 페이지 **검토용 미리보기**입니다.
정식 공개 전 사내 피드백 수집을 위한 저장소이며, 아직 비공개 초안입니다.

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 2단계 — Haptic Design Lab 소개 페이지 (랜딩 페이지) |
| `insert-block.html` | 1단계 — dwanatech.com `/actuator-driver` 페이지용 삽입 블록 |
| `gallery/` | 데모기 갤러리 (포트폴리오) — 작업 상태는 `gallery/README.md` 참조 |

## 상태

- 표시된 측정 수치(공진 주파수·정착 시간·최대 가속도)는 전부 실측 전 예시 자리값입니다. 페이지 내 "(실측 전)" 표기가 붙은 값은 실측 데이터로 교체되어야 합니다.
- "같은 부품, 전혀 다른 느낌" 섹션의 지그 3종 비교 버튼은 실제로 동작합니다(순수 JS, 외부 의존성 없음).
- 슬로모션+사운드 영상 자리는 아직 비어 있습니다.

## 피드백

페이지 우측 하단 "✉ 피드백 보내기" 버튼으로 보내주세요. 어떤 섹션인지 번호와 함께 적어주시면 반영이 빨라집니다.
